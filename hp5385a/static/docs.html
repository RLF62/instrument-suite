HP 5385A Frequency Counter

Quick start

Connect the USB-GPIB adapter to the counter at GPIB address 03. Open Classic or Modern. Use 10 MHz Check to test the internal reference, or select Input A/B to count an external signal. The page reads through the suite's shared adapter service.

The B input is rated 90–1000 MHz; the A input is rated 10 Hz–100 MHz. Observe the front-panel 7 V RMS maximum for B.

Controls

Remote controls: Buttons are enabled. Each 10 MHz Check request selects A Frequency first so repeated web clicks do not enter diagnostics. Live readings use a direct addressed GPIB read, including when the data-ready status bit is clear.

Measurement: A frequency, A period, B frequency, 10 MHz check. Gate: 0.1, 1, or 10 seconds. Input A: 20× attenuation and 100 kHz low-pass filter. Reset restarts the current gate. Blue choices reflect commands sent from this page; a physical front-panel change is not automatically read back.

Readings and chart

The live reading and chart use the counter's HP-IB output. A missing data-ready indication or bus timeout is shown as an error, not a zero reading. Chart history stays in this browser. Drag panels on desktop, or use the panel move buttons; Customize layout can hide or restore panels.

Connection

This development controller runs at port 8085 on the server. If the counter reports an error, read the front-panel ERROR code and clear it with the physical Reset/Local key before retrying. The HP 5385A uses legacy commands such as FU1, CK, and GA2, rather than SCPI.
