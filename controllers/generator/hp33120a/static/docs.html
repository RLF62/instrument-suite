Quick start

  1. Open Classic or Modern view and select Read configuration.
  2. Choose waveform, frequency, amplitude, offset and the assumed load.
  3. Use the knob or arrow controls for small staged frequency changes.
  4. Select Apply waveform now. The controller writes once, reads the instrument back, and updates the main display only after verification.

The teal staged-frequency label near the knob changes immediately. The large simulated display is verified-state feedback and changes after the instrument confirms the new configuration.

Waveform settings

SettingPurpose
FunctionSine and square up to 15 MHz; triangle and ramp up to 100 kHz.
FrequencyEnter a value and unit. The browser step follows the selected frequency increment.
AmplitudeConfigured peak-to-peak voltage (Vpp), interpreted using the selected load assumption.
OffsetDC offset. Valid range depends on amplitude and load.
LoadChoose 50 Ω or High-Z to match the connected equipment. This is an assumption, not a measurement.

The photographed function keys stage matching waveforms. The Enter Number hotspot is the immediate Apply action.

Rotary knob and increments

Drag or wheel over the knob to stage the selected frequency. The knob indicator rotates with the value. Set the increment in Hz before turning: smaller steps are useful for tuning, while larger steps move quickly across a range. Arrow keys provide the same staged adjustment. None of these controls writes to hardware until Apply.

Sweep setup

  1. Read sweep configuration.
  2. Select a preset or enter start, stop, sweep time and spacing.
  3. Select a sweep increment. Increment and spacing are stored with custom presets.
  4. Use Apply sweep setup. This configures the sweep but leaves sweep mode off.
  5. Use the separate confirmed Start sweep action. Stop sweep returns the instrument to a fixed-frequency state.

Changing any saved preset field marks that selection as modified. Save it as Custom to preserve those values. The Audio preset uses 20 Hz–20 kHz, logarithmic spacing and a 10 Hz increment.

Start and stop must differ. The controller accepts sweep endpoints from 0.01 Hz up to the selected waveform limit and sweep times from 0.001 to 500 seconds.

Display appearance

Use Customize layout and Display appearance to resize or hide panels and adjust simulation/text scale. Classic view retains the photographic panel; Modern view presents the same verified configuration in a compact instrument-style layout. Navigation follows the current Classic/Modern preference for other HP tools; the scope has one view.

What the readback means

The controller reads the 33120A configuration after every write and checks waveform, frequency, Vpp, offset, load, trigger and mode state. A successful readback means the instrument accepted those settings. It is not a measurement of the voltage at the output connector.

Waveform and sweep setup use explicit Apply actions. Sweep setup and sweep start are deliberately separate. The web application serializes requests through the shared GPIB broker and rejects a stale configuration token if the instrument changed after the last read.

Troubleshooting

Message or symptomWhat to do
No configuration readbackConnect the adapter, confirm the GPIB address/configuration, then use Read configuration.
Configuration changedAnother operation changed the instrument. Read again, review, then Apply.
Mode or trigger warningTurn modulation/burst/sweep off and use immediate triggering before applying a fixed waveform.
Instrument errorRead the message, correct the setting or physical setup, then read configuration again. Automatic retries are intentionally avoided.
Display did not changeCheck the status message. The main display waits for successful hardware readback; the staged label shows the pending frequency.
Installer Remove disabledOlder manually shared installations require migration. A catalog-installed standalone service can be removed while preserving settings.

Architecture and endpoints

The Flask/Gunicorn service listens on port 8084. It never opens VISA or USB directly; gpib_client.py sends bounded requests to the suite broker. Read-only status is at /api/generator/status. Control actions are same-origin JSON posts under /api/control/generator/.
