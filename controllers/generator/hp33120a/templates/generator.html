No configuration readback.

These read buttons are optional diagnostics. Apply automatically verifies identity, reads the current safety state, programs the staged settings, and reads them back in one protected GPIB transaction.

Staged waveform settings

Edits are staged until Apply. The output is always potentially active. Load describes the connected termination; it does not switch the physical 50 Ω output impedance.

Instrument settings may round to the documented resolution; the display shows actual readback. Apply sets Vpp units, programs the waveform immediately and sets square duty to 50%. First version requires AM, FM, FSK, burst and sweep off, with immediate trigger. Disconnect sensitive loads before programming; changes may produce transients.

Adjust the staged settings, then click Apply. Identity and safety state are checked automatically.

Staged sweep setup

Prepare an amplifier-test sweep using the current waveform and voltage settings. Apply setup leaves sweep OFF; Start below is a separate confirmed action. The existing fixed-frequency output can remain active.

Read sweep configuration to verify amplitude, offset and configured load assumption.

Start above stop sweeps downward. Triangle/ramp maximum is 100 kHz. Change amplitude/offset in the waveform form first, then read sweep configuration again. Load is a configured assumption, never a measurement; the source impedance stays 50 Ω.

Edits stay in this browser until Apply.

Run the read-back sweep

Start immediately repeats the last read-back sweep with IMM triggering. Staged edits are not applied by Start. Stop disables sweep mode only; the signal may remain active. Neither control isolates the amplifier. There is no automatic stop when this page closes.
